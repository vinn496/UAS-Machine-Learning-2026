## 📌 Deskripsi
Proyek ini melakukan analisis graf pada dataset RetailRocket menggunakan **Neo4j** dan **Python**. Analisis mencakup:
- Wrangling Data (Filtering periode P1 & P2)
- Exploratory Data Analysis (EDA)
- Vector Space Modelling (VSM)
- Perhitungan Similarity
- Sistem Rekomendasi berbasis K-Nearest Neighbors (KNN)

## 🛠️ Teknologi yang Digunakan
- **Database:** Neo4j (Cypher Query Language)
- **Bahasa Pemrograman:** Python 3.12
- **Library:** `neo4j`, `pandas`, `scikit-learn`, `scipy`, `networkx`, `matplotlib`
